# 建科洁净供应链平台

湖北建科科技集团 · 洁净工程垂直领域产业互联网平台官网。

一个纯静态营销门户站，聚焦半导体、新能源电池、生物医药、数据中心等洁净工程场景，提供从智能寻源、供应商管理、电子招投标到履约协同、供应链金融的一站式数字化服务。

## 页面结构

| 文件 | 模块 |
| --- | --- |
| `index.html` | 首页（品牌定位 + 六板块导流 + CTA） |
| `value.html` | 平台价值（四大价值维度） |
| `features.html` | 核心功能（1中台 + 6大中心） |
| `category.html` | 品类矩阵（六大品类） |
| `serve.html` | 服务对象（四类客户、下游行业） |
| `data.html` | 数据驾驶舱（运营指标看板） |
| `finance.html` | 供应链金融（六大金融产品） |
| `join.html` | 供应商入驻流程 |
| `common.css` | 公共样式 |
| `common.js` | 导航/页脚注入、数字滚动、滚动动画、移动端菜单 |

## 技术说明

- 纯静态 HTML + CSS + 原生 JS，无构建步骤、无依赖
- 业务系统入口：`https://scm.hbjkjt.com/supplyChain/home`

## 本地预览

直接用浏览器打开 `index.html` 即可，或本地起一个静态服务器：

```bash
python -m http.server 8000
```
